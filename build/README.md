# Application icon

The editable artwork is [`favicon.svg`](../src/renderer/public/favicon.svg).
It uses the application's blue palette with an accessibility figure and cursor.

- `icon.png`: 512 × 512 transparent image used by the Electron window.
- `icon.ico`: Windows icon with 16, 20, 24, 32, 40, 48, 64, 128, and 256 pixel
  images, used by the EXEs, installer, uninstaller, and shortcuts.

Keep these exports and the SVG in sync when changing the artwork.
